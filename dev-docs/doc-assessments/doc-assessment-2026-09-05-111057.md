   describes 1×1, 1×2/2×1, and 2×2 Swap. `USER_GUIDE_LAYOUTS.md` documents
   asymmetric 3-pane layouts on key **3**. **Impact:** Medium.

   Annotations/shortcuts guides include **G**. **Impact:** Low–Medium.

   `USER_GUIDE_SHORTCUTS.md` / Help → Keyboard Shortcuts (F1). **Impact:** Low.
4. **Swap wording** — Fixed (Muse review): UI is right-click **Swap** →
   **Swap with Window 1–4** / **Show Window Map**, not “Swap with View” and not
   2×2-only layout menus. **Impact:** High (was incorrect after first draft).
5. **CONFIGURATION “Slice Position Lines” vs UI “Show Slice Location Lines”** —
   label drift between config guide and View menu. **Impact:** Medium
   (discoverability).
6. **Hub “Last updated” 2026-08-29** vs current `main` features (navigator
   options, sync, customizations) — freshness signal only; not a single claim
   error. **Impact:** Low (process).
