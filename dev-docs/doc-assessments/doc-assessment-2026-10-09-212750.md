### F2 — Settings reference had no MPR limits (INCOMPLETE → fixed)

`CONFIGURATION.md` listed only `mpr_cache_max_mb`. Added the **MPR Limits** group and the `mpr_session_cap` / `mpr_view_cap` keys with their defaults.

### F3 — Architecture and source maps named the removed single-slot design (STALE → fixed)

`ARCHITECTURE.md`, `SOURCE_LAYOUT.md` and the module tree described a "detached navigator thumbnail" and `MPRNavigationMixin` as detach/assign/clear. Updated, including two new contract rows (registry ownership; one canonical slice setter).

### F4 — Source docstring plan reference (STALE → fixed)

Updated the module docstring in `src/core/mpr_session_registry.py` to the archived `dev-docs/plans/completed/MPR_MULTI_SESSION_AND_LINKED_VIEWS_PLAN.md`. This comment-only correction leaves the file at 600 lines.
